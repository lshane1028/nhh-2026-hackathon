# UI·아트 및 상점 팩 개봉 인수인계

작성일: 2026-08-08

작업 브랜치: `images`

## 이번 업데이트 범위

- 화투패와 화면 전체가 따로 놀지 않도록 Galmuri 기반 도트 타이포그래피와 픽셀 UI 규칙을 전 화면에 적용했습니다.
- 상점 카드 크기, 본문·버튼 글자 크기와 한국어 문구를 손봐 가독성을 높였습니다.
- 부적, 도록, 화공, 금단, 우두머리, 카드 효과, 강화 표식, 화투 묶음 이미지를 게임 데이터 태그와 연결했습니다.
- 화투 묶음 개봉 화면을 보자기 꾸러미의 봉인을 뜯는 연출로 전면 교체했습니다.
- 상점 카드 설명이 화면 위쪽에서 잘리는 문제를 수정했습니다.
- 패에 부여된 효과마다 서로 다른 픽셀 광택·문양·파동 효과가 보이도록 구현했습니다.

## 에셋과 비율 규칙

- 생성 이미지: `public/assets/generated/`
- 픽셀 글꼴: `public/assets/fonts/`
- 에셋 태그 연결: `app/components/generated-asset.ts`
- 에셋 목록: `assets/manifest.json`
- 라이선스: `docs/ASSET_LICENSES.md`, `docs/THIRD_PARTY_NOTICES.md`
- 상점 카드, 부적, 화투 묶음처럼 카드형으로 노출되는 이미지는 화투패와 같은 `2:3` 비율을 사용합니다.
- 카드 위에 겹치는 효과·강화 표식은 정사각형 오버레이로 두며 원본 카드 비율을 바꾸지 않습니다.
- 현재 생성 에셋은 WebP 131개입니다: 부적 58, 도록 14, 화공 15, 금단 10, 묶음 2, 우두머리 4, 효과 12, 강화 표식 16.

## 팩 개봉 구현

- 화면 및 상태 연출: `app/GameApp.tsx`의 `PackPickModal`
- 사운드: `app/audio/game-sfx.ts`
- 스타일과 모션: `app/components/pixel-direction.css`
- 묶음을 클릭하면 보자기와 매듭이 흔들리고 봉인이 갈라진 뒤 후보 패가 차례로 공개됩니다.
- 후보는 플레이스홀더가 아니라 실제 `HwatuCard`를 사용하므로 월·종류·원본 카드 그림과 효과 설명이 함께 표시됩니다.
- 개봉, 패 공개, 선택 소리는 외부 음원 없이 Web Audio로 합성합니다. 브라우저 정책상 첫 사용자 클릭 뒤에만 소리가 납니다.
- 카드 하나를 선택해 후보 목록이 바뀌어도 최초 공개 모션과 소리가 다시 재생되지 않도록 공개 개수를 모달 생성 시 고정했습니다.

## 카드 효과 표현

- 클래스 생성: `app/components/HwatuCard.tsx`
- 효과별 시각 규칙: `app/components/pixel-direction.css`
- 동전, 짝패 강화, 무거운 달, 메아리, 행운, 광·열끗·띠·피 변환, 쌍피, 금박, 오기 효과에 서로 다른 색과 움직임을 부여했습니다.
- 접근성 설정에서 동작 줄이기가 켜지면 반복 애니메이션은 멈춥니다.
- 주의: 현재 `game/content/card-effects.ts` 기준으로 대부분의 카드 효과는 데이터와 시각 표시만 있고 실제 점수 계산 로직은 아직 연결되지 않았습니다. `stubborn`을 제외한 효과의 게임 규칙 구현은 별도 작업이 필요합니다.

## 상점 툴팁 수정

- 상점 구역의 `overflow`와 `clip-path`로 인해 설명창이 잘리던 문제를 제거했습니다.
- 위쪽 두 상점 구역에서는 설명창이 카드 아래 방향으로 열립니다.
- 호버·키보드 포커스 상태에서 해당 구역과 카드의 쌓임 순서를 올려 인접 패널에 가리지 않게 했습니다.

## 유지보수 주의사항

- `pixel-direction.css`는 기존 화면 스타일 뒤에 로드되어 최종 아트 디렉션을 덮어씁니다. 로드 순서를 바꾸면 카드 크기와 툴팁 배치가 되돌아갈 수 있습니다.
- 새 이미지 태그를 추가할 때 `generated-asset.ts`의 분류 규칙과 `assets/manifest.json`을 함께 갱신해야 합니다.
- 픽셀 이미지는 `image-rendering: pixelated`를 유지하고 임의의 블러·고해상도 보간 필터를 적용하지 않습니다.
- 툴팁을 포함하는 부모 요소에 `overflow: hidden`이나 `clip-path`를 다시 주지 않습니다.
- `.openai/hosting.json`의 기존 Sites 프로젝트 식별자는 현재 유효하지 않으므로 배포 전에 새 프로젝트 연결이 필요합니다.
