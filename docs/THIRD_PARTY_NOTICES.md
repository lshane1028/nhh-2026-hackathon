# Third-party notices

프레임워크와 라이브러리의 정확한 버전은 `package-lock.json`을 기준으로 한다.

- React / React DOM
- Next.js 호환 계층 및 vinext
- Vite
- Tailwind CSS
- Cloudflare Vite plugin / Wrangler
- TypeScript / ESLint

- 제작: quiple
- 프로젝트: https://github.com/quiple/galmuri
- 라이선스: SIL Open Font License 1.1
- 로컬 라이선스 사본: `public/assets/fonts/GALMURI-OFL.txt`

폰트 파일 자체를 판매하지 않는 범위에서 게임에 포함·사용·재배포할 수 있다.
