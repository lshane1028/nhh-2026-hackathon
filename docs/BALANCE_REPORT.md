# 밸런스 보고서

## 기준값

- 점수: `floor(최종 월 합 × 최종 배수)`
- 기본 제출/버리기: 각 4회
- 기본 손패: 8장
- 기본 부적 슬롯: 5칸
- 시작 자금: 4냥
- 목표: 1월 300 → 3월 800 → 6월 3,500 → 9월 16,000 → 12월 75,000
- 무한 달력: 한 바퀴마다 목표 ×1.6

## 고 곡선

- 고를 선언할 수 있는 최소 이번 승부 점수: 목표의 15%
- 1고 문턱: `max(이번 승부 점수×1.75, 이번 승부 점수+목표×0.12)`
- 2고 문턱: `max(이번 승부 점수×1.60, 이번 승부 점수+목표×0.18)`
- 3고 문턱: `max(이번 승부 점수×1.50, 이번 승부 점수+목표×0.25)`
- 정산 배율: 0고 ×1.00 / 1고 ×1.15 / 2고 ×1.35 / 3고 ×1.70

## 자동 검증

- 표준 덱 48장과 월별 4장 구성
- 즉시/비밀 족보 17종과 수집 족보 8종
- 점수 연산 순서와 최고점 후보 선택
- 누적 점수와 진행 중 수집·숙련의 실패 롤백 및 중복 정산 방지
- 콘텐츠 129개 ID·태그·설명·수량
- 시작→제출→정산→장터→영구 개조→계약 상태 전이

현재 값은 프로토타입 1차 곡선이다. 실제 참가자 플레이 로그에서는 월별 클리어율, 고 선언률, 고 실패율, 장터 구매율을 수집해 6·9·12월 목표와 희귀 부적 가중치를 우선 조정한다.
