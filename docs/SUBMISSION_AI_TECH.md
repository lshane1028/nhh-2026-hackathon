# AI 활용 기술 문서

## 활용 방식

OpenAI Codex를 다음 작업에 사용했다.

- 기획서를 규칙·콘텐츠·UI 모듈로 분해
- 화투 48장과 족보 판정의 정합성 검사
- 월 합 × 배수, 누적 점수·이번 승부·진행 중 수집·숙련, 고 문턱·롤백 순수 함수 구현
- 콘텐츠 카탈로그와 텍스트 플레이스홀더 UI 작성
- 경계값·상태 전이 테스트 생성 및 오류 수정
- 제출용 AI 활용·라이선스·밸런스 문서 정리

사람이 정한 핵심 방향은 화투 테마, 고·스톱 위험 구조, 이미지 생성 금지, 텍스트 태그 기반 프로토타입이다. 런타임에는 생성형 AI나 유료 API를 호출하지 않아 오프라인 시연과 재현이 가능하다.

## 재현성과 검증

- 모든 런은 표시된 문자열 시드와 RNG 커서로 재현된다.
- 규칙 엔진은 React와 분리된 순수 TypeScript 모듈이다.
- 자동 테스트는 카드 구성, 17개 즉시/비밀 족보, 8개 수집 족보, 점수 연산 순서, 고 실패 롤백, 콘텐츠 수량, 상점, 런 상태 전이를 검사한다.
- 사용 프롬프트는 `docs/PROMPTS/`, 작업 로그는 `docs/AI_USAGE_LOG.md`에 남긴다.
