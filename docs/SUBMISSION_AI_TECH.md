# 《경화수월》 AI 활용 기술 문서 원고

## 활용 방식

AI는 제작 도구로 사용했으며 게임 실행 중에는 어떤 생성형 AI API도 호출하지 않는다.

- OpenAI Codex: 기획서 모듈화, 규칙·상태·UI 구현, 리팩터링, 테스트, 최종 규칙·브랜드·연출 통합
- Anthropic Claude (Cowork): 짓고땡 규칙 전환, 완전 탐색 기반 밸런스 조정, 튜토리얼과 문서 정리
- OpenAI 이미지 생성: 화투, 부적, 비결서, 화공패, 금단패, 두목, 계절 인물, 시작 덱과 UI 배경 제작

## 협업 절차

`사람이 결정 → AI가 생성 → 자동 검증 → 사람이 채택` 순환을 적용했다.

1. 바꿀 것, 지킬 것, 삭제할 것과 판정 가능한 합격 기준을 먼저 명시한다.
2. 코드에는 테스트를, 이미지에는 결정론적 후처리 절차를 함께 요구한다.
3. Vitest, TypeScript, ESLint, 프로덕션 빌드 검증을 수행한다.
4. 실제 화면에서 카드, 툴팁, 제출 연출, 보스, 장터를 플레이 검수한다.
5. 프롬프트, 활용 로그, 자산 장부와 커밋으로 추적한다.

## 재현성과 검증

- 모든 런은 문자열 시드와 RNG 커서로 재현된다.
- 규칙 엔진은 React와 분리된 순수 TypeScript 모듈이다.
- 최종 검증일 2026-08-12 기준으로 31개 파일, 231개 테스트가 통과했다.
- 테스트 범위에는 규칙·상태·콘텐츠·저장·화면 불변식·생성 자산·오디오·브랜드·계절 보스 연출이 포함된다.
