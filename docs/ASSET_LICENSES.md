# 에셋 및 라이선스 장부

게임에 사용되는 시각 자산의 출처와 제작 방식을 기록한다.

| 범주 | 현재 자산 | 출처 | 권리 메모 | 상태 |
|---|---|---|---|---|
| 기본 화투 48장 | 한국풍 도트 화투 아틀라스 | 사용자 제공 원본을 바탕으로 OpenAI 이미지 생성 | 사용자는 프로젝트 이용 권리 확인을 완료했다고 알림 | 사용 중 |
| 부적 56종 | 2:3 한지 부적 카드 | OpenAI 이미지 생성 | 프로젝트용 생성 자산. 제거된 2종의 참고 그림은 파일로만 보존 | 사용 중 |
| 비결서·화공·금단·패 묶음 | 2:3 세로 카드 | OpenAI 이미지 생성 | 프로젝트용 생성 자산 | 사용 중 |
| 우두머리 12종 | 2:3 괘패형 보스 아트와 계절 배경 | OpenAI 이미지 생성 | 프로젝트용 생성 자산 | 사용 중 |
| 카드 효과·강화·판본·인장 | 정사각 오버레이 인장 | OpenAI 이미지 생성 | 프로젝트용 생성 자산 | 사용 중 |
| UI 장식 | HTML/CSS 및 문자 기반 장식 | 자체 코드 | 프로젝트 자체 제작 | 사용 중 |

세부 파일 경로와 생성 방식은 `assets/manifest.json`에서 관리한다. 원본 생성 결과는 Codex 생성 이미지 저장소에 보존하고, 게임에는 WebP 파생본을 사용한다.
