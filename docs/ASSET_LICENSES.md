# 에셋 및 라이선스 장부

현재 프로토타입에는 외부 이미지, 생성 이미지, 음원, 폰트를 추가하지 않는다. 게임 안의 모든 시각 요소는 HTML/CSS와 텍스트 플레이스홀더이며, 각 콘텐츠의 `assetTag`가 향후 참가자 제공 이미지 파일과 연결된다.

| 범주 | 현재 자산 | 출처 | 라이선스/권리 | 상태 |
|---|---|---|---|---|
| 카드 이미지 | 텍스트 플레이스홀더 | 자체 코드 | 참가자 프로젝트 | 이미지 대기 |
| 부적 이미지 | 텍스트 플레이스홀더 | 자체 코드 | 참가자 프로젝트 | 이미지 대기 |
| 두목 이미지 | 텍스트 플레이스홀더 | 자체 코드 | 참가자 프로젝트 | 이미지 대기 |
| UI 아이콘 | 유니코드·CSS 도형 | 표준 문자/자체 코드 | 외부 파일 없음 | 사용 |
