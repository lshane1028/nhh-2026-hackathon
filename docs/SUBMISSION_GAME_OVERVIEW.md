# 《꽃판: GO!》 게임 소개·실행 문서

## 한 줄 소개

48장의 열두 달을 고쳐 나만의 족보 엔진을 만들고, 이번 승부 점수와 진행 중 수집패를 걸어 고·스톱을 선택하는 싱글 플레이 화투 로그라이크 덱빌더다.

## 구현된 핵심

- 화투 48장, 즉시 족보 13종, 비밀 족보 4종, 수집 족보 8종
- `floor(월 합 × 배수)` 계산과 후보별 실제 최고점 선택
- 누적 점수 / 이번 승부 점수 / 진행 중 수집 / 진행 중 숙련을 한 번에 안전하게 정산
- 최대 3고, 단계별 문턱, 실패 시 현재 체인 전체 롤백
- 1~12월 목표 곡선, 두목, 날씨, 무한 달력
- 시작 덱 10종, 부적 36종, 화공패 15종, 금단패 10종, 비결서 13종
- 손질 8종, 판본 4종, 낙관 4종, 묶음 5종, 계절 계약 8쌍
- 흔들기·폭탄, 광박·피박·멍박, 나가리 재승부
- 시드 기반 재현, 자동 저장, 모바일·키보드 접근성

## 실행

```bash
npm install
npm run dev
```

브라우저에서 `http://localhost:3000`을 연다. 별도 계정, API 키, 백엔드가 필요하지 않다.

## 기본 조작

- 카드를 클릭해 1~5장 선택
- `자동`은 실제 최고점 족보를 선택하고, 후보 버튼으로 메인 족보를 고정 가능
- `족보 제출` 후 안전 정산·고·스톱 선택
- 9월 술잔은 동물패/쌍피 역할을 직접 전환
- 덱 보기에서 카드의 월·종류·손질·판본·낙관과 이미지 교체 태그 확인

## 프로토타입 자산 정책

인게임 그림은 의도적으로 제작하지 않았다. 모든 자리에 사람이 읽을 이름과 고유 `assetTag`를 표시해 후속 아트 제작과 교체가 가능하다.
