# 《경화수월》 게임 소개·실행 문서 원고

## 한 줄 소개

화투 48장으로 짓고땡을 만들고, 목표를 넘긴 순간 고와 스톱 사이에서 위험을 거는 싱글 플레이 로그라이크 덱빌더다.

## 핵심 규칙

- 손패 8장, 제출 4회, 버리기 3회로 한 판을 시작한다.
- 2~5장을 고르며 먼저 고른 두 장은 끗패(배수), 나머지는 짓(월 합)이 된다.
- 제출 점수는 `floor(월 합 × 배수)`이고, 한 판 동안 모은 고스톱 점수도 별도로 더한다.
- 목표를 넘긴 순간 스톱으로 판돈을 확정하거나, 고를 선언해 더 높은 문턱과 보상에 도전한다.
- 1~12월을 진행하며 3·6·9·12월에는 계절 두목 규칙이 추가된다.

## 현재 규모와 표현

- 화투 48장, 끗패 족보 14종, 수집 족보 11종
- 부적 56종, 비결서 22종, 화공패 15종, 금단패 10종, 두목 12종
- 22단계 스포트라이트 튜토리얼, 시드 재현, 브라우저 자동 저장
- 《경화수월》 전용 배경과 전통 문양, 카드 제출·금단패·계절 두목 전용 연출
- 타이틀·장터·일반 판·보스 판 BGM과 화투·칩·구매 효과음
- GitHub Pages 자동 배포
