# 《꽃판: GO!》 게임 소개·실행 문서

## 한 줄 소개

기본 화투 48장으로 전통 놀이 **짓고땡**을 만들어 점수를 내고, 목표를 넘긴 순간 고를 외칠지 스톱할지 거는 싱글 플레이 화투 로그라이크 덱빌더다.

## 왜 짓고땡인가

포커 족보를 화투 그림으로 갈아끼운 복제품을 피하려고, 실제로 화투로 하는 놀이에서 제출 규칙을 가져왔다. 짓고땡은 낸 패를 **짓**(월 합을 맞추는 쪽)과 **끗패**(족보로 겨루는 쪽) 둘로 나눠 읽는데, 이 구조가 `월 합 × 배수` 점수식과 그대로 맞물린다.

원래 짓고땡은 5장을 고정으로 내지만, 여기서는 **2~5장 자유 제출**로 일반화했다. 두 장만 내는 길을 항상 열어 두어 진입 장벽을 낮추고, 장수를 늘릴수록 짓이 커져 점수가 뛰게 만들었다.

## 구현된 핵심

- 화투 48장, 끗패 족보 14종(공개 11 · 광땡 3), 수집 족보 8종
- 짓/끗패 분할 완전 탐색과 최고점 갈래 자동 선택
- `floor(월 합 × 배수)` 순서 있는 연산 파이프라인
- 최대 3고, 단계별 문턱, 초과 달성 방지 장치, 실패 시 런 종료
- 1~12월 목표 곡선, 두목 12종, 날씨, 무한 달력
- 부적 53종(손패·소지 부적·런 기록을 읽는 연계 조커 10종 포함), 화공패 15종, 금단패 10종, 비결서 14종, 카드 묶음 2종, 계절 계약 8쌍
- 발라트로식 스포트라이트 튜토리얼 (플레이 + 장터)
- 시드 기반 재현, 자동 저장, 단일 뷰포트 레이아웃

## 실행

```bash
npm install
npm run dev
```

브라우저에서 `http://localhost:3000`을 연다. 별도 계정, API 키, 백엔드가 필요하지 않다.

## 기본 조작

- 카드를 클릭해 2~5장 선택. 드래그는 없다
- 고른 패에 붙는 푸른 `짓`·붉은 `끗` 표식으로 어느 쪽에 들어갔는지 확인
- `제출` 후, 목표를 넘긴 순간에만 고·스톱 선택
- 9월 술잔은 점수를 낸 뒤 동물/쌍피 중 어디에 기록할지 선택
- 손패 정렬은 월 순과 광·동물·띠·피 순 두 가지

## 프로토타입 자산 정책

인게임 그림은 의도적으로 제작하지 않았다. 모든 자리에 사람이 읽을 이름과 고유 `assetTag`를 표시해 후속 아트 제작과 교체가 가능하다.
