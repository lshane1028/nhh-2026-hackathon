# 현재 규칙 전환 작업 인수인계 (2026-08-10)

## 이번 작업에서 완료한 사항

### 제출 규칙

- 제출할 때 **플레이어가 처음 고른 두 장을 항상 끗패**로 사용한다.
- 세 번째 이후에 고른 패만 짓으로 계산한다.
- 손패 역할 표기, 제출 가능 여부 미리보기, 실제 점수 계산, 제출 연출이 모두 같은 선택 순서를 사용한다.
- 밸런스 탐색 테스트도 플레이어가 끗패 두 장을 먼저 고르는 실제 조작을 모사한다.

### 계절 결산과 장터

- 계절 결산의 계약 선택 카드를 크게 확대했다.
- 장터 상단에 현재 보유 부적을 항상 표시한다.
- 보유 부적을 눌러 판매할 수 있다.
- 장터에 `덱 보기` 버튼을 추가했다.

### 첫 화면과 시작 덱

- 첫 화면의 실험용 `선택 규칙`을 제거했다.
- 첫 화면이 한 화면 높이 안에 들어오도록 전체 높이와 여백을 압축했다.
- 시작 덱을 총 5종으로 정리했다.
  - 기본 화투패: 처음부터 사용 가능
  - 홍단패: 3월 클리어 시 해금
  - 청단패: 6월 클리어 시 해금
  - 먹장패: 9월 클리어 시 해금
  - 엽전패: 12월 클리어 시 해금
- 해금 기록은 브라우저 저장소에 유지한다.
- 다섯 덱은 현재 CSS 무늬로 서로 다른 뒷면을 표시한다.

### 문장과 옛 규칙 흔적 1차 정리

- 핵심 튜토리얼 문장을 자연스러운 한국어로 다시 작성했다.
- 자동 최적 조합처럼 오해하게 만들던 안내를 삭제하고, `첫 두 장은 끗패, 이후는 짓`으로 명시했다.
- 화면에 남아 있던 `CALENDAR`, `COLLECTION`, 실험 규칙 영문 표기를 한국어로 바꿨다.
- `무월` 노출 요소를 `팔방패`로 바꾸고, 현재 규칙의 모든 종류 취급 효과로 연결했다.
- `연월/월쌍`을 전제로 한 보스 설명을 제거했다.
- 옛 역월 보스는 `안개 병풍`으로 바꾸고 두 장을 뒤집어 보이게 하는 현재 규칙으로 교체했다.
- `윤달 달력` 부적은 `반짓 셈판`으로 바꿨다.
- 사용자 문장에서 `엔진`, `리롤` 같은 직역투를 가능한 범위에서 자연스러운 표현으로 교체했다.

### 화면 동작 1차 반영

- 드로우 카드가 오른쪽 덱 위치에서 손패로 이동하도록 시작 위치를 변경했다.
- 버린 카드는 손패 아래로 빠져나가도록 변경했다.
- 제출 강조 화면은 중앙 초록 판을 채우되 상단 부적 줄을 덮지 않도록 범위를 낮췄다.
- 월 시작 화면에 이번 판의 일반/우두머리 규칙과 적용 규칙 제목을 분명히 표시했다.

## 반드시 이어서 해야 할 사항

### 1. 제목 협의 후 로고 제작

사용자가 제목을 함께 정한 뒤 로고를 만들자고 명시했으므로 임의 확정하지 않았다. 제목이 정해지기 전에는 로고 이미지를 만들지 말 것.

제안 후보:

1. **열두 판** — 짓을 맞추고, 끗을 세우고, 고를 외쳐라
2. **달패** — 첫 두 장으로 승부를 세우는 열두 달 덱빌딩
3. **화투승부** — 열두 달을 엮어 판을 키우는 덱빌딩

현재 코드의 임시 제목 `꽃판: GO!`는 협의가 끝난 뒤 선택한 제목과 부제로 교체해야 한다.

### 2. 이미지 생성과 실제 에셋 교체

이번 작업에서는 이미지 생성 크레딧을 대량 사용하지 않았다. 다음 항목은 반드시 새 그림을 생성하고 실제 파일로 연결해야 한다.

- 시작 덱 5종의 고유한 화투 뒷면 이미지
- `팔방패` 금단패 이미지 (`assetTag: forbidden:eight-directions`)
- `안개 병풍` 우두머리 이미지. 현재는 기존 `boss:reverse-calendar` 에셋 태그를 임시 재사용 중이다.
- 제목 확정 후 새 로고와 제목 아래 부제 그래픽
- 아래 전수 감사에서 발견되는 옛 규칙 기반 부적/금단패/비결서/우두머리 이미지

이미지는 기존 게임의 짙은 먹색·주홍·금박·한지 질감 방향을 유지하되, 카드 안의 기능이 한눈에 구별되도록 구성할 것.

### 3. 모든 콘텐츠의 규칙/문장/이미지 전수 감사

이번 작업은 사용자가 직접 지적한 용어와 핵심 튜토리얼을 우선 고쳤다. 다음 카탈로그를 항목별로 전부 읽고 현재 실제 코드 효과와 대조해야 한다.

- 부적 58종
- 금단패 10종
- 비결서 22종
- 화공패 15종
- 강화/판본/인장 전체
- 우두머리 12종, 날씨 4종, 계약 8쌍
- 상점, 결과 화면, 규칙 도움말, 말풍선, 로그의 모든 사용자 문장

각 항목은 다음 네 가지를 모두 확인한다.

1. 이름이 현재 규칙과 맞는가
2. 설명이 실제 구현 효과와 정확히 같은가
3. 옛 용어·직역투·내부 개발 용어가 남아 있지 않은가
4. 그림이 이름과 기능을 직관적으로 보여주는가

### 4. 월 시작 화면의 완전한 아트 재구성

현재는 정보 구조와 문구만 우선 정리했다. 클리어 화면과 같은 짙은 판 배경, 규칙패 등장 애니메이션, 일반 규칙/우두머리 규칙의 시각적 등급 차이, 규칙 적용 효과음을 포함한 완전한 재디자인이 남아 있다.

### 5. 드로우/버리기/부적 적용 최종 연출

- 드로우 시작 위치는 덱 쪽으로 옮겼지만 실제 덱 맨 위 카드가 빠지는 연속 동작을 시각 검증하고 보강해야 한다.
- 버리기는 아래로 빠지도록 했지만 카드 사이 간격과 재정렬 타이밍을 실제 플레이로 조정해야 한다.
- 제출 중 적용되는 부적을 상단 부적 줄에서 직접 점등/확대하는 연결은 아직 완료되지 않았다.
- 중앙 초록 강조 화면이 모든 화면비에서 부적을 가리지 않는지 실제 브라우저로 최종 확인해야 한다.

### 6. 첫 화면 반응형 최종 확인

데스크톱 높이는 한 화면에 맞췄지만, 낮은 노트북 화면과 모바일 미디어 쿼리에서 기존 스타일이 다시 큰 여백을 덮어쓸 수 있다. 1366×768, 1440×900, 1920×1080에서 스크롤 없이 전부 보이는지 확인하고 조정할 것.
