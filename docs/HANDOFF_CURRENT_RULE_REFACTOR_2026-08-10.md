- 제출할 때 **플레이어가 처음 고른 두 장을 항상 끗패**로 사용한다.

## 2026-08-10 인수인계 완료 표기 재감사

사용자 지적에 따라 기존의 “완료” 문구를 실제 상태 전이와 화면 코드에 다시 대조했다. 다음 항목은 완료라고 적혀 있었지만 동작이 빠져 있거나 설명과 달랐고, 이번 재감사에서 수정했다.

- **장터 보유 부적 위치**: 상품 위의 별도 세로 줄을 제거하고 장터 현판과 같은 최상단 줄로 옮겼다. 부적별 칸을 나누고, 호버/키보드 포커스 시 실제 효과·발동 순서·판매가를 표시한다. 상품 진열부는 없어진 부적 줄만큼 세로 공간을 더 사용한다.
- **소각 꾸러미 규칙**: 무작위 2/4장 중 일부를 고르는 잘못된 흐름을 폐기했다. 작은 꾸러미는 현재 덱 전체에서 정확히 2장, 큰 꾸러미는 정확히 4장을 고르며 선택을 마치기 전에는 창을 닫을 수 없다. 큰 꾸러미 가격은 작은 꾸러미의 두 배보다 높다.
- **대서고 계약**: 설명만 있고 비결 꾸러미 추첨에 연결되지 않았던 누락을 수정했다. 계약이 두 겹이면 `stats.yakusPlayed`에서 가장 많이 제출한 족보를 찾고, 대응 비결서를 모든 크기의 비결 꾸러미 첫 후보로 보장한다.
- **동네 책방 계약**: 고정형 장터로 바뀐 뒤 의미가 사라진 “출현률 상승”을 현재 구조에 맞춰 비결서점 상품 +1권으로 다시 연결했다.
- **화공 조합/명장 조합 계약**: 사용되지 않던 계약 효과를 패 꾸러미 생성에 연결했다. 한 겹은 효과패 출현률을 높이고, 두 겹은 후보에 판본 또는 낙관이 붙을 수 있게 한다.
- **내부 시작 덱 식별자 노출**: 새 판 로그의 `deck_red` 같은 내부 값을 실제 덱 이름으로 교체했다.
- **새로고침 오류**: 시작 덱 해금 정보를 첫 렌더에서 브라우저 저장소로 읽어 서버 화면과 달라지던 하이드레이션 오류를 수정했다.
- **말풍선 최상위 레이어**: 덱 카드·장터 상품·보유 부적·플레이 부적 설명을 모두 `document.body` 포털로 통일했다. 실제 렌더된 말풍선 크기를 측정해 상하좌우 12px 안전 영역 안으로 재배치하므로 스크롤 영역, 상품 칸, 모달의 `overflow`에 잘리지 않는다.

재감사 후 의도적으로 남은 작업은 아래 “남은 사용자 결정”의 제목·로고 확정과 배포 대상 복구뿐이다. 나머지 항목은 해당 동작의 회귀 테스트 또는 콘텐츠 정합성 테스트를 둔다.

## 남은 사용자 결정

- **보류 부적 2종 재설계**: `열두 달의 화공`과 `오방 도깨비`는 규칙 설명과 조작 부담이 커 현재 카탈로그에서 제거했다. 저장 파일에 남은 인스턴스도 로드 시 자동 제거한다. 추후 다시 넣을 때는 화공의 월 선택 UI와 오방 도깨비의 네 수집줄 동시 착지 연출을 먼저 설계하고, 플레이어가 결과를 제출 전에 명확히 예측할 수 있을 때만 복구한다. 기존 그림 파일과 엔진 훅은 재설계 참고용으로 남겨 두었다.

- 제목과 로고는 사용자가 “제목부터 같이 협의한 뒤 만들자”고 정했으므로 임의 확정하지 않았다. 위의 제목 후보 중 하나를 고르거나 새 제목을 정한 뒤 로고와 부제를 제작한다.
- `.openai/hosting.json`에 적힌 기존 사이트가 현재 존재하지 않아 배포는 진행할 수 없다. 로컬 구현과 빌드는 완료됐다.
