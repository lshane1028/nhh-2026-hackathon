# 네 자리 수직 슬라이스 설계

## 변경 이유

초기 버전은 플레이어만 패를 내고 판주는 목표 점수만 바꾸는 구조였다. 화투 규칙을 계산할 수는 있었지만 상대에게 패를 빼앗기는 감정, 차례를 기다리는 긴장, 판의 소란스러움이 없었다.

수정 버전은 플레이어와 판주 세 명이 같은 48장 덱을 나눠 갖고 실제로 경쟁한다.

## 패 분배

| 위치 | 장수 |
|---|---:|
| 플레이어 손패 | 5 |
| 비 장수 손패 | 5 |
| 매화 선비 손패 | 5 |
| 월식 여우 손패 | 5 |
| 바닥패 | 8 |
| 산패 | 20 |
| 합계 | 48 |

한 라운드에는 네 명이 차례로 손패 한 장을 내고, 각자 산패 한 장을 뒤집는다. 다섯 라운드가 끝나면 48장을 모두 사용한다.

## 판주 성향

- 비 장수: 먹을 수 있는 광을 가장 높은 가치로 평가한다.
- 매화 선비: 띠를 우선해 플레이어의 단 계열 족보를 방해한다.
- 월식 여우: 열끗을 우선해 고도리와 동물패 빌드를 견제한다.

판주는 정답을 읽거나 플레이어 패를 보지 않는다. 공개된 바닥패와 자기 손패만 이용하는 규칙 기반 AI다.

## 일반 고스톱과 다른 점

1. 판술
   - 플레이어만 산패 순서, 월 판정, 턴 점수를 비틀 수 있다.
   - 무작위 결과를 그대로 받지 않고 기력을 언제 사용할지 선택한다.

2. 판주 성향
   - 상대마다 노리는 카드 종류가 달라 같은 패 구성도 다른 압박을 만든다.

3. 경쟁형 고·스톱
   - 목표 점수뿐 아니라 현재 네 자리 순위를 함께 본다.
   - 선두일 때 스톱으로 순위를 확정하거나, 고로 남은 패에 배수를 건다.
   - 뒤지고 있을 때도 목표를 넘겼다면 고를 걸어 역전을 노릴 수 있다.

4. 로그라이트 확장 기반
   - 이후 판술 덱, 노리개, 계절별 판주와 지속 강화 요소를 붙일 수 있다.

## 손맛 연출

### 패 내기

- 손패가 중앙으로 145ms 동안 가속한다.
- 착지 직전 회전이 정돈된다.
- 저역 충격음과 플라스틱 마찰음이 겹친다.
- 충격파, 원형 파편, 화면 흔들림이 동시에 발생한다.
- 플레이어의 타격은 판주보다 강하게 표현한다.

### 산패 뒤집기

- 고역 노이즈와 상승하는 짧은 음을 사용한다.
- 뒤집힌 패도 중앙에 착지한 뒤 월 맞춤 결과를 계산한다.

### 갈무리

- 먹은 패를 최대 네 장까지 겹쳐 해당 자리로 빠르게 쓸어간다.
- 두 번 상승하는 짧은 음으로 획득을 알린다.

### 족보와 고

- 족보는 저음 징과 2차 배음을 사용한다.
- 고는 종이·나무 충격음과 낮은 도장음을 사용한다.
- 화면 중앙에 짧은 인장이 찍힌 뒤 바로 플레이로 돌아간다.

## 사운드 구현

사운드는 외부 파일 없이 Web Audio API로 실시간 합성한다. 생성형 AI가 플레이 중 음성이나 문장을 만들지 않는다.

- 카드 타격: 밴드패스 노이즈 + 삼각파 저역
- 카드 뒤집기: 고역 노이즈 + 짧은 상승 사인파
- 갈무리: 두 단계 삼각파
- 판술: 세 단계 상승음
- 족보: 감쇠하는 저음 사인파
- 고 도장: 저역 삼각파 + 짧은 노이즈

브라우저 자동재생 정책을 지키기 위해 첫 사용자 입력에서 AudioContext를 활성화한다.
