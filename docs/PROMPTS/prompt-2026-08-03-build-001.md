# 구현 프롬프트 요약

사용자는 기존 기획서에 제안된 시스템을 모두 포함하는 웹게임 프로토타입 구현을 요청했다. 다음 제약을 우선한다.

1. 화투 48장, `끗 × 흥`, 수집 족보, 챙기기·고·스톱을 실제 플레이 가능하게 구현한다.
2. 파일을 규칙 엔진·콘텐츠·런 상태·UI로 모듈화한다.
3. 이미지나 생성형 시각 자산을 만들지 않는다.
4. 카드·부적·화공패·두목마다 교체 가능한 `assetTag`를 제공하고 텍스트 플레이스홀더로 렌더링한다.
5. NAN 2026 제출 조건에 맞는 링크 실행형 웹게임과 증빙 문서 구조를 유지한다.
